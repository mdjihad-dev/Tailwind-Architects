# G3 Architects - Tailwind

A responsive architecture website recreated with Tailwind CSS. The project focuses on utility-first styling, responsive layouts, and converting a multi-section design into a structured frontend page.

## Tech Stack

- HTML5
- Tailwind CSS
- Responsive Web Design

## Highlights

- Responsive navigation
- Hero and feature sections
- Team image grid
- Architecture-focused content sections
- Utility-first styling with Tailwind CSS

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/Tailwind-Architects.git
cd Tailwind-Architects
```

## Project Focus

This project was built to strengthen Tailwind CSS skills, responsive layout techniques, utility composition, and translating a visual design into a clean frontend implementation.
